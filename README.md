## 👋 Tentang Kami

**ICT Unit** adalah tim teknologi informasi yang mengembangkan dan memelihara sistem internal perusahaan — mulai dari aplikasi keuangan, penganggaran, manajemen estate & properti, hingga portal otorisasi dan website perusahaan.

- 🏢 Fokus pada **aplikasi bisnis internal** yang stabil, aman, dan mudah dipelihara
- 🔄 Modernisasi sistem lama ke arsitektur yang lebih baru (CodeIgniter 2 → CodeIgniter 4, HMVC)
- 🌐 Membangun **landing page & web modern** dengan Next.js dan TypeScript
- 📚 Mendokumentasikan setiap proyek untuk kelancaran serah terima (handover)

## 🧩 Ruang Lingkup Sistem

| Modul | Deskripsi |
| :-- | :-- |
| 💰 **Finance** | Pengelolaan transaksi & pelaporan keuangan |
| 📊 **Budget** | Perencanaan dan monitoring anggaran |
| 🌴 **Estate** | Operasional & manajemen area estate |
| 🏠 **Home** | Sistem manajemen properti |
| 🔐 **Otorisasi** | Alur persetujuan (approval) & hak akses |
| 🛠️ **Teknik & Internal** | Aplikasi pendukung operasional |
| 🌐 **Harvestlink** | Landing page produk |
